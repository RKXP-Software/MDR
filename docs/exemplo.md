# MDR

Editor e visualizador de **Markdown** com edição e pré-visualização lado a lado.

## Recursos

- Visualização em tempo real
- Tema claro e escuro
- Realce de sintaxe nos blocos de código

### Tarefas

- [x] Abrir um arquivo
- [x] Editar o texto
- [ ] Salvar com `Ctrl+S`

## Código

```ts
function saudacao(nome: string): string {
  return `Olá, ${nome}!`
}

console.log(saudacao('MDR'))
```

## Tabela

| Modo | Atalho |
| --- | --- |
| Somente editor | `Ctrl+1` |
| Dividido | `Ctrl+2` |
| Somente visualização | `Ctrl+3` |

> Escreva à esquerda, veja o resultado à direita.
